# Rikka for Obsidian

A private, Scrivener-inspired project Binder plugin for the LIFE2.0 Obsidian vault.

## Installation

This repository is private. Install on another device with Obsidian42 BRAT and a read-only GitHub fine-grained token limited to this repository (Contents: read-only). Add `Ramirikka/obsidian-rikka` as a beta plugin, then enable **Rikka** in Community plugins.

## Release files

BRAT downloads `main.js`, `manifest.json`, and `styles.css` from the matching GitHub release. The Scrivener-style Binder icons are embedded in `main.js` so they install on mobile too. The `assets/` folder in the source is retained for local development.

## Privacy

Keep this repository private. Vault-specific `data.json` is excluded and must never be committed.
